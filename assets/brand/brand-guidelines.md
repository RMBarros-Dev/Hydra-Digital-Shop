# Identidade visual — Hydra Digital Shop

**Versão:** 2.0 · Identidade independente de projeto educacional e demonstrativo.

## Conceito
O símbolo combina um H geométrico estrutural com dois losangos em destaque. A composição remete à organização de catálogo, seleção de jogos e conexão entre interface e serviços. Evita referências literais a carrinhos, controles, cabeças de hidra e ícones tecnológicos genéricos.

## Paleta
| Token | HEX | Uso |
|---|---|---|
| Grafite | `#191C20` | Base da marca |
| Grafite médio | `#292D32` | Superfícies |
| Marfim | `#F5F0E6` | Tipografia e símbolo |
| Laranja | `#E86F38` | Destaques |
| Cinza quente | `#B8B6B0` | Texto auxiliar |

## Tipografia
- Títulos: sans-serif robusta, Arial/Helvetica como fallback.
- Texto: Inter, Segoe UI ou Arial.
- Evitar neon, efeitos metálicos e gradientes roxos.

## Arquivos
- `logo.svg`: símbolo principal para fundos escuros.
- `logo-light.svg`: versão para fundos claros.
- `banner.svg`: banner para README.
- `project-mark.svg`: assinatura horizontal.
- `brand-guidelines.md`: este guia.

## Regras
1. Preservar proporções, contraste e área livre mínima de 10% da largura do símbolo.
2. Testar legibilidade em 32 px e 64 px.
3. Não apresentar o projeto como loja comercial com pagamentos reais.
4. Não aplicar a identidade a interfaces de produção sem revisar os tokens do frontend.
5. Esta identidade não altera backend ASP.NET Core, frontend React, persistência ou .NET Aspire.
