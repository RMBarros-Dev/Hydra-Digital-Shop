# Diretrizes de identidade visual — Hydra Digital Shop

## Posicionamento

Projeto demonstrativo de loja digital, desenvolvido para explorar arquitetura Full Stack e integração entre backend e frontend. A identidade deve transmitir uma experiência digital contemporânea e uma arquitetura técnica organizada, sem sugerir operação comercial real ou serviços de pagamento ativos.

**Assinatura:** Jogos digitais. Experiência Full Stack.

## Conceito visual

O símbolo é um monograma H geométrico, construído por duas hastes verticais e uma conexão central. Dois losangos laranja atravessam o eixo central e representam os dois lados integrados da aplicação: experiência de interface e serviços de backend. Não utilizar dragões, carrinhos de compra, controles de videogame ou ícones genéricos de tecnologia.

## Paleta oficial

| Token | HEX | Aplicação |
|---|---|---|
| Grafite | `#191C20` | Fundo principal |
| Grafite médio | `#292D32` | Superfícies e profundidade |
| Marfim | `#F5F0E6` | Texto e fundos claros |
| Laranja | `#E86F38` | Símbolo, acentos e chamadas |
| Cinza quente | `#B8B6B0` | Texto secundário |

## Ativos oficiais

- `assets/brand/logo.svg`: monograma H para fundos escuros.
- `assets/brand/logo-light.svg`: monograma H para fundos claros.
- `assets/brand/banner.svg`: banner horizontal do repositório.
- `assets/brand/project-mark.svg`: assinatura horizontal da marca.

## Tipografia

Priorizar uma sans-serif contemporânea e robusta. Fallbacks: Arial, Helvetica e sans-serif. Manter títulos curtos, hierarquia clara e bom contraste.

## Regras de aplicação

- Preservar proporções, área de respiro e geometria dos SVGs.
- Usar a versão clara em superfícies marfim e a versão principal em fundos grafite.
- Não introduzir novas cores sem revisão da paleta.
- Não modificar tokens ou componentes funcionais da interface para acomodar a identidade.
- Não comunicar pagamentos reais, operação comercial, catálogo licenciado ou serviços externos que não estejam comprovados no código.

## Escopo técnico representado

A identidade acompanha a proposta documentada: backend em ASP.NET Core/.NET 10, frontend em React 19 e TypeScript, Vite, Tailwind CSS, Entity Framework Core, SQL Server LocalDB e orquestração local com .NET Aspire. O checkout é demonstrativo e não movimenta dinheiro real.
